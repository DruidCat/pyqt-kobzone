Все дела Дорожной карты и выполненные дела ВЫПОЛНЕНО перенесены
в GitHub Issues: https://github.com/DruidCat/pyqt-kobzone/issues

Создать задание/баг:
	gh issue create -t "Кратко описать" -b "Подробно как воссоздать ошибку или дело" -l "ошибка или сделать"

Сокращенная запись создания:
	gh issue create -t "Краткое описание"

Увидеть полный список дел:
	gh issue list

Увидеть полный список дел вместе с закрытыми:
	gh issue list --state all

Увидеть подробное описание -b:
	gh issue view номер

Изменить задани/баг:
	gh issue edit номер --title "Новый заголовок" --body "Новое подробное описание проблемы"

Добавить Label или его удалить: --add-body --remove-body --add-label --remove-label 
	gh issue edit номер --add-label "bug,ui" --remove-label "question"
	
Удалить дело или ошибку:
	gh issue delete номер --yes

Закрыть дело из issue, для этого в коммите нужно в конце написать Close #номер:
	commit -m "Исправил ошибку Close #22"

Метки (-l) в GitHub — это фиксированный набор
	bug:				Непредвиденная проблема или ошибка.
	documentation:		Улучшения или дополнения в документации.
	duplicate:			Дубликат существующей задачи.
	enhancement:		Запрос на новую функцию или улучшение.
	good first issue:	Хорошая задача для новичков.
	help wanted:		Требуется помощь мейнтейнера.
	invalid:			Задача больше не актуальна.
	question:			Требуется дополнительная информация.
	wontfix:			Работа над задачей не будет продолжаться.
